# แบบประเมินผู้สูงอายุเบื้องต้น (One Page) — คลินิกผู้สูงอายุ โรงพยาบาลบ้านกรวด

เว็บแอปสำหรับคัดกรองผู้สูงอายุ 13 ด้าน คำนวณ BMI (ข้อ 2) และ OSTA index (ข้อ 13) ให้อัตโนมัติ
ติดตั้งลงมือถือหรือคอมพิวเตอร์ได้ (PWA) และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## ความสามารถ
- **ต้องเข้าสู่ระบบก่อนใช้งาน** ผู้ใช้ใหม่ลงทะเบียนแล้วรอผู้ดูแลอนุมัติ
- ประเมิน 13 ด้าน สรุปผลทันที พร้อมแถบความคืบหน้า
- **บันทึกผล** ลงระบบกลาง (Google Sheets) ทุกคนในทีมเปิดดู แก้ไข และค้นหาด้วย EL ได้ พร้อมบันทึกว่าใครเป็นผู้บันทึก
- ไม่มีอินเทอร์เน็ตก็กรอกและกดบันทึกได้ ระบบจะส่งให้อัตโนมัติเมื่อออนไลน์
- **ส่งออก Excel (CSV)** ของทุกรายการ เพื่อนำไปทำสถิติ
- **พิมพ์ / PDF** ได้ในหน้า A4 หน้าเดียว และ **คัดลอกสรุปผล** วางลงเวชระเบียนหรือ LINE ได้
- ผู้ดูแลระบบอนุมัติ ระงับ ตั้งผู้ดูแล และรีเซ็ตรหัสผ่านผู้ใช้ได้ในเมนู “จัดการผู้ใช้”

## โครงสร้างไฟล์
```
index.html             หน้าแอปทั้งหมด (HTML + CSS + JavaScript)
manifest.webmanifest   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                  service worker สำหรับใช้งานออฟไลน์
icons/                 ไอคอนแอป
apps-script/Code.gs    โค้ดระบบกลาง (Google Sheets) สำหรับรวมข้อมูลของทุกคน
```

## วิธีเปิดใช้งาน
**ลองใช้ในเครื่อง:** ดับเบิลคลิก `index.html` ได้เลย (แต่ฟีเจอร์ติดตั้งแอปและออฟไลน์จะยังไม่ทำงาน)

**เปิดผ่านเซิร์ฟเวอร์ในเครื่อง (ทุกฟีเจอร์ทำงาน):**
```
npx serve .
```
หรือ `python -m http.server 8000` แล้วเปิด http://localhost:8000

## นำขึ้นเว็บ (ฟรี)
แอปนี้เป็นไฟล์ static ล้วน อัปโหลดทั้งโฟลเดอร์ขึ้นที่ไหนก็ได้ที่เป็น HTTPS เช่น
- **GitHub Pages:** สร้าง repository → อัปโหลดไฟล์ทั้งหมด → Settings › Pages › Deploy from branch (main)
- **Netlify Drop:** ลากโฟลเดอร์นี้ไปวางที่ https://app.netlify.com/drop
- **Vercel / Cloudflare Pages:** เชื่อม repository แล้ว deploy ได้ทันที ไม่ต้องตั้งค่า build

## ติดตั้งลงมือถือ
- **Android (Chrome):** เปิดเว็บ → กดปุ่ม “ติดตั้งแอป” บนหน้าเว็บ หรือเมนู ⋮ › ติดตั้งแอป
- **iPhone/iPad (Safari):** เปิดเว็บ → ปุ่มแชร์ › เพิ่มไปยังหน้าจอโฮม

## ระบบกลางและบัญชีผู้ใช้ (Google Sheets + Apps Script)
ข้อมูลผลการประเมินอยู่ในแผ่นงาน **ผลการประเมิน** และบัญชีผู้ใช้อยู่ในแผ่นงาน **ผู้ใช้งาน** (สร้างให้อัตโนมัติ)

**ตั้งค่า / อัปเดตโค้ด:**
1. เปิด Google Sheet › **ส่วนขยาย › Apps Script** → ลบโค้ดเดิมทั้งหมด → วางโค้ดจาก `apps-script/Code.gs` → บันทึก
2. ถ้าเป็นการตั้งค่าครั้งแรก: **Deploy › การทำให้ใช้งานได้รายการใหม่** › ประเภท **เว็บแอป** (เรียกใช้ในฐานะ: ฉัน · ผู้มีสิทธิ์เข้าถึง: ทุกคน) แล้วนำ URL (`/exec`) ไปใส่ใน `const SYNC_URL` ของ `index.html`
3. ถ้าเป็นการอัปเดตโค้ด: **Deploy › จัดการการทำให้ใช้งานได้ › ✏️ แก้ไข › เวอร์ชัน: เวอร์ชันใหม่ › ทำให้ใช้งานได้** (URL เดิมใช้ต่อได้)

**บัญชีผู้ใช้:**
- ผู้ที่ลงทะเบียน **คนแรก** จะเป็นผู้ดูแลระบบอัตโนมัติ คนต่อไปต้องรอผู้ดูแลอนุมัติ
- รหัสผ่านเก็บแบบ hash + salt (ไม่มีใครอ่านรหัสจริงได้ แม้เปิด Sheet)
- ใส่รหัสผิด 5 ครั้ง บัญชีจะถูกล็อก 15 นาที
- บัญชีที่ถูกระงับจะออกจากระบบทันทีทุกเครื่อง
- ห้ามแก้คอลัมน์ salt / hash ในแผ่นงานผู้ใช้งาน และคอลัมน์ “ข้อมูล (JSON)” ในแผ่นงานผลการประเมิน

## เรื่องข้อมูลและความเป็นส่วนตัว
- ผลการประเมิน (ระบุผู้ป่วยด้วย EL เท่านั้น ไม่เก็บชื่อ-สกุลและ HN) เก็บใน Google Sheet ของโรงพยาบาล ให้แชร์ Sheet เฉพาะผู้ดูแลที่จำเป็น
- ในเครื่องผู้ใช้จะเก็บเพียงสถานะการเข้าสู่ระบบ แบบฟอร์มที่กรอกค้าง และรายการที่รอส่ง ซึ่งจะถูกลบเมื่อกด “ออกจากระบบ”
- เครื่องที่ใช้ร่วมกันหลายคน ให้กด “ออกจากระบบ” ทุกครั้งหลังใช้งาน
- ไฟล์ CSV ที่ส่งออกมีข้อมูลส่วนบุคคลด้านสุขภาพ เก็บและส่งต่ออย่างระมัดระวังตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล

## เมื่อแก้ไขไฟล์แล้วอัปโหลดใหม่
ให้เปลี่ยนเลขเวอร์ชันใน `sw.js` (`const CACHE = 'onepage-v6'` → `'onepage-v7'`)
เพื่อให้เครื่องที่ติดตั้งแอปไว้แล้วโหลดไฟล์ใหม่
