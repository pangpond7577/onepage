# แบบประเมินผู้สูงอายุเบื้องต้น (One Page) — เว็บแอป

เว็บแอปสำหรับคัดกรองผู้สูงอายุ 13 ด้าน คำนวณ BMI (ข้อ 2) และ OSTA index (ข้อ 13) ให้อัตโนมัติ
ติดตั้งลงมือถือหรือคอมพิวเตอร์ได้ (PWA) และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## ความสามารถ
- ประเมิน 13 ด้าน สรุปผลทันที พร้อมแถบความคืบหน้า
- **บันทึกผล** เก็บไว้ในเครื่อง แล้วเปิดดูหรือแก้ไขย้อนหลังได้จาก “ประวัติการประเมิน” (ค้นหาด้วยชื่อหรือ HN ได้)
- **ส่งออก Excel (CSV)** ของทุกรายการ เพื่อนำไปทำสถิติ
- **สำรองข้อมูล / นำเข้า** (ไฟล์ .json) เพื่อย้ายข้อมูลไปเครื่องอื่นหรือกันข้อมูลหาย
- **พิมพ์ / PDF** ได้ในหน้า A4 หน้าเดียว
- **คัดลอกสรุปผล** แล้ววางลงเวชระเบียนหรือ LINE ได้
- ถ้าปิดหน้าไประหว่างกรอก ข้อมูลที่กรอกค้างไว้จะกลับมาเมื่อเปิดใหม่

## โครงสร้างไฟล์
```
index.html             หน้าแอปทั้งหมด (HTML + CSS + JavaScript)
manifest.webmanifest   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                  service worker สำหรับใช้งานออฟไลน์
icons/                 ไอคอนแอป
apps-script/Code.gs    โค้ดระบบกลาง (Google Sheets) สำหรับรวมข้อมูลของทุกคน
```

## วิธีเปิดใช้งาน
**ลองใช้ในเครื่อง:** ดับเบิลคลิก `index.html` ได้เลย (แต่ฟีเจอร์ติดตั้งแอปและออฟไลน์จะยังไม่ทำงาน)

**เปิดผ่านเซิร์ฟเวอร์ในเครื่อง (ทุกฟีเจอร์ทำงาน):**
```
npx serve .
```
หรือ `python -m http.server 8000` แล้วเปิด http://localhost:8000

## นำขึ้นเว็บ (ฟรี)
แอปนี้เป็นไฟล์ static ล้วน อัปโหลดทั้งโฟลเดอร์ขึ้นที่ไหนก็ได้ที่เป็น HTTPS เช่น
- **GitHub Pages:** สร้าง repository → อัปโหลดไฟล์ทั้งหมด → Settings › Pages › Deploy from branch (main)
- **Netlify Drop:** ลากโฟลเดอร์นี้ไปวางที่ https://app.netlify.com/drop
- **Vercel / Cloudflare Pages:** เชื่อม repository แล้ว deploy ได้ทันที ไม่ต้องตั้งค่า build

## ติดตั้งลงมือถือ
- **Android (Chrome):** เปิดเว็บ → กดปุ่ม “ติดตั้งแอป” บนหน้าเว็บ หรือเมนู ⋮ › ติดตั้งแอป
- **iPhone/iPad (Safari):** เปิดเว็บ → ปุ่มแชร์ › เพิ่มไปยังหน้าจอโฮม

## ระบบกลาง: รวมข้อมูลของทุกคนใน Google Sheets
เมื่อเปิดใช้ ทุกครั้งที่กด “บันทึกผล” ข้อมูลจะถูกส่งไปเก็บใน Google Sheet ด้วย (ถ้าไม่มีเน็ตจะส่งให้อัตโนมัติเมื่อออนไลน์)
และในหน้า “ประวัติการประเมิน” จะมีแท็บ **ทุกคน (ระบบกลาง)** ที่ต้องใส่รหัสผ่านทีมก่อนดู

**ตั้งค่า (ทำครั้งเดียว):**
1. สร้าง Google Sheet ใหม่ด้วยบัญชี Google ของหน่วยงาน
2. เมนู **ส่วนขยาย › Apps Script** → ลบโค้ดเดิมทั้งหมด → วางโค้ดจาก `apps-script/Code.gs`
3. แก้บรรทัด `const PASSWORD = 'CHANGE_ME';` เป็นรหัสผ่านทีม → กดบันทึก
4. กด **การทำให้ใช้งานได้ (Deploy) › การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. กดอนุญาตสิทธิ์ (ถ้าขึ้นคำเตือน ให้กด ขั้นสูง › ไปที่โปรเจกต์) แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
6. ใส่ URL นั้นใน `index.html` ที่บรรทัด `const SYNC_URL = '';` แล้วอัปโหลดขึ้นเว็บใหม่

> ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy › จัดการการทำให้ใช้งานได้ › แก้ไข › เวอร์ชันใหม่ (URL เดิมจะยังใช้ได้)

## เรื่องข้อมูลและความเป็นส่วนตัว
- ถ้ายังไม่ตั้งค่าระบบกลาง ข้อมูลเก็บใน **localStorage ของเบราว์เซอร์ในเครื่องนั้นเท่านั้น**
- ถ้าตั้งค่าระบบกลางแล้ว ข้อมูล (รวมชื่อ-สกุลและ HN) จะอยู่ใน Google Sheet ด้วย ให้แชร์ Sheet เฉพาะผู้เกี่ยวข้อง และไม่เปิดเผยรหัสผ่านทีม
- ข้อมูลจะหายถ้าล้างข้อมูลเบราว์เซอร์ หรือใช้โหมดไม่ระบุตัวตน ควรกด “สำรองข้อมูล” เป็นระยะ
- ไฟล์ CSV/JSON ที่ส่งออกมีข้อมูลส่วนบุคคลด้านสุขภาพ เก็บและส่งต่ออย่างระมัดระวังตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล

## เมื่อแก้ไขไฟล์แล้วอัปโหลดใหม่
ให้เปลี่ยนเลขเวอร์ชันใน `sw.js` (`const CACHE = 'onepage-v4'` → `'onepage-v5'`)
เพื่อให้เครื่องที่ติดตั้งแอปไว้แล้วโหลดไฟล์ใหม่
